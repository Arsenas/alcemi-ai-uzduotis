# Alcemi AI Widget

**What it is**  
A responsive AI assistant widget UI for an e-shop.
Shows suggested topics (“chips”), lets you type your own, and displays AI answers

**Main features**

- Works on both phone and computer.
- Suggested question buttons you can scroll and tap.
- Type in a box and send with Enter.
- Answer view centers the reply.

**How to run**

```bash
npm install
npm run dev       # start locally
```
